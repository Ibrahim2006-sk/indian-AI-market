# Indian AI Stock Market Simulator

A high-level **multi-agent market simulation** where behavior emerges from interactions between five AI archetypes:

- **Fear Agent**: de-risks aggressively during drawdowns.
- **Greed Agent**: chases momentum and upside shocks.
- **News Agent**: translates headline polarity into buying/selling pressure.
- **Retail Trader Agent**: mixes trend following, social sentiment, and noisy reactions.
- **Institutional Agent**: mean-reversion with position/risk limits.

## Why this is impressive

Instead of hardcoding a single market direction, each agent has a distinct objective. Their conflicting actions create:

- feedback loops,
- volatility clusters,
- regime shifts,
- and non-linear price moves.

That emergent behavior is the point: the market path is generated by interaction, not scripted outcomes.

## Run the simulator

```bash
python3 src/simulator.py --steps 60 --start-price 120 --seed 42
```

### Options

- `--steps`: Number of market ticks (default `60`)
- `--start-price`: Initial stock price (default `120.0`)
- `--seed`: Random seed for reproducible runs (default `42`)

## Example output (abridged)

- Prints periodic step snapshots (price, net demand, sentiment, confidence).
- Prints final summary with return and each agent's cash, shares, and NAV.

## Architecture

`src/simulator.py` includes:

1. `MarketState` and `TradeIntent` data models.
2. Five agent classes implementing independent decision logic.
3. `Simulator` engine that applies market impact + noise + sentiment drift.
4. Summary report for post-simulation performance attribution.

This setup is intentionally modular so you can later add:

- multiple stocks,
- order-book depth,
- macro events,
- reinforcement-learning policies,
- execution slippage models.
